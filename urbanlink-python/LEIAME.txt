2. REQUISITOS DA SPRINT 4 -> ONDE ESTÃO NO CÓDIGO
   - Menus e submenus: main(), menu_usuarios(), menu_pontos(), menu_consultas(), menu_exportar()
   - CRUD (Oracle): Create cadastrar_usuario | Read listar_usuarios/buscar_usuario/consultas |
     Update alterar_usuario, atualizar_pontos | Delete excluir_usuario, excluir_pontos
   - Exportação JSON: exportar_json() -> pasta exportacoes/
   - API pública: api_externa.py (Open-Meteo, sem chave) - previsão do tempo da viagem e sugestão de deslocamento
   - Relevância: os dados ficam no mesmo banco da API Java/front-end, então refletem no sistema web.

3. EXPLICAÇÃO DO CÓDIGO (para o vídeo)
   - Funções: cada ação do menu é uma função (ex.: adicionar_pontos); banco.py concentra o SQL; api_externa.py a API.
   - Laços: while nos menus e nas validações de entrada; for para listar registros e calcular estatísticas.
   - Estruturas de dados: dict (usuário, sessão, linhas do banco), list (histórico, valores), tuple (opções de menu).
   - Arquivos: json.dump grava exportacoes/<nome>_<data-hora>.json com "with open" (fecha o arquivo sozinho).
   - Tratamento de erros: try/except/else/finally; ErroBanco (ORA-xxxxx traduzidos) e ErroApi
     (timeout, sem internet, HTTP, JSON inválido); executar() captura e mostra mensagem amigável.
   - Banco: oracledb com binds (:nome) contra SQL injection; conectar() faz commit, rollback e close;
     retirar_pontos usa UPDATE atômico (WHERE saldo_pontos >= :qtd).
   - API: requests.get com timeout de 10s; o resultado vira dict e é usado em sugerir_deslocamento().
